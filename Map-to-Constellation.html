A FIELD GUIDE

Real places. Your pattern.

01

Find somewhere that matters.

Search for a place or enter latitude, longitude. Drag to pan; use the wheel, a pinch, or + / − to zoom.

02

Make your marks.

Choose a shape, any color, and size. In Plot mode, click or tap the map. Select an existing point to style it individually. Choose Done editing to set the style for new points. Use exact coordinate entry for precise locations.

03

Keep the pattern, leave the map.

PNG and SVG contain all your icons, including points outside the viewport. Export uses the current map zoom, translates the whole pattern together, and crops around the full icon outlines. Nothing is fit, stretched, or independently repositioned.

Scale: The preview fits the card; the actual files preserve the map's pixel spacing. Zooming deliberately changes map scale. Use the lock button to prevent zoom changes. PNG is 1×; SVG has matching intrinsic dimensions.

Saving: This browser saves your project locally. Export a JSON backup before clearing browser data or switching devices. Opening a backup restores geographic coordinates, styling, world copies, and zoom.

Privacy & connectivity: No account or application server. Your points stay in this browser unless you save a file. Viewing a map sends tile-area requests to OpenStreetMap. Place search sends your submitted query to Nominatim. Live maps and place search require internet and a localhost or HTTPS page.

Limits: 2,000 points. PNG: 8,192 px per side and 16 megapixels; larger patterns remain available as SVG. Map coverage ends at ±85.0511° latitude. Screen-space Web Mercator spacing is preserved, not ground-distance ratios.

Keys: P: plot · V: navigate · Esc: deselect · Delete: remove selected · Ctrl/⌘ Z: undo · Ctrl/⌘ Shift Z: redo. With the map focused, arrow keys pan and Enter plots at the center.
